# 与宗萨钦哲仁波切对话

一个模拟与宗萨蒋扬钦哲仁波切对话的**单文件、纯前端、零依赖** Web 应用。所有回应均基于其公开出版的著作与开示整理，借由问答的形式，帮助使用者照见自己的内心。

> 🔒 本应用为**非商业的学习用途**，回应系基于公开资料的模拟，**并非仁波切本人**。内容版权归原作者所有，如有不当请联系删除。

## 特性

- **纯前端、零依赖**：全部逻辑内嵌于单个 [index.html](./index.html)，无后端、无大模型调用，打开即用。
- **分层对话引擎**，按优先级匹配：
  - **危机 / 高敏感安全拦截**：识别自杀、自残、未成年、堕胎等高危表达，优先给出关怀回应与真实求助渠道，绕过一切模糊匹配。
  - **《八万四千问》原著匹配**：基于二字词重合度，命中书中真实问答。
  - **深度说理流（Flow）**：焦虑、执着、无常、情绪、快乐、关系、别离等深度主题，提供连贯递进的长回应，并在会话内去重、支持上下文衔接。
  - **软着陆兜底**：未命中时先接住情绪、再反问，并推荐相关问题。
- **手机号注册登录体系**：注册需自定义「法号」，登录态持久化，会话数据按用户隔离（纯前端 localStorage，仅供学习演示）。
- **来源分级标注**：区分「原文出处（著作）」「观点出处（整理）」「观点参考（推断）」。
- **沉浸式体验**：击磬入定开场、背景禅音（自动播放 / 可手动暂停）、莫兰迪色系 UI、打字机渲染。

## 快速开始

直接用浏览器打开 `index.html` 即可；或启动一个本地静态服务器：

```bash
python3 -m http.server 4173
# 然后访问 http://localhost:4173/index.html
```

## 测试

[tests.html](./tests.html) 是一套**浏览器内单元测试**（零依赖），通过 iframe 加载 `index.html` 并对核心函数（危机拦截、主题匹配、flow 去重、深度文案长度等）做断言。

在本地服务器下访问 `http://localhost:4173/tests.html` 即可查看结果。

## 技术说明

- 单文件架构，使用 Tailwind CSS（CDN）、Lucide 图标、Web Audio API（颂钵 / 背景禅音）。
- 知识库以 JS 数组形式内嵌，匹配采用 bigram 相似度 + 关键词命中。
- 用户消息渲染经 HTML 转义，防范存储型 XSS。
